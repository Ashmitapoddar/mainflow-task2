Simple Login and Registration System

This project is a basic PHP and MySQL-based login and registration system. It allows users to create an account with a username, email, and secure password, and then log in using their email and password. The system includes:
• Password strength validation (must include uppercase, lowercase, number, special character, and be at least 8 characters)
• Secure password storage using hashing
• User feedback for registration and login errors
• Session management for user authentication
• Clean and modern interface styled with CSS

This system is ideal for learning or as a starting point for more advanced authentication features.
